# Primary Actuarial Source Documents & Traceability

`reserving-kernels` implements published, peer-reviewed property & casualty actuarial reserving, stochastic variance, tail extrapolation, dependence, severity layering, and capital risk-measure methods directly from primary literature. Every kernel listed below is numerically verified in [`tests/source_benchmarks.rs`](../tests/source_benchmarks.rs).
