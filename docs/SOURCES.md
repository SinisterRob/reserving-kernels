# Primary Actuarial Source Documents & Traceability

`reserving-kernels` implements published, peer-reviewed property & casualty actuarial reserving, stochastic variance, tail extrapolation, dependence, severity layering, and capital risk-measure methods directly from primary literature. Verification spans the integration benchmark suite ([`tests/source_benchmarks.rs`](../tests/source_benchmarks.rs)), the sub-annual suite ([`tests/subannual.rs`](../tests/subannual.rs)), and per-module unit tests; each entry below states its evidence type (**published reproduction**, **analytical identity**, **cross-implementation parity**, **synthetic recovery**, or **smoke check**).
